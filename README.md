Meu tio pediu pra mim baixar musica de Natanzinho Lima mas eu nao queria ter escutar 1000 anuncions, entao desenvolvi o meu.


Aplicação simples desenvolvida em *Python* para extrair áudio de vídeos e convertê-lo para *MP3*.


---

## 🚀 Tecnologias

- Python 3.12
- yt-dlp
- FFmpeg
- Docker
- Docker Compose
